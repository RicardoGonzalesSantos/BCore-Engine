What is BCore Engine?

BCore Engine is a lightweight, modular C++ framework built on top of raylib. It provides a clean, English-first API for building 2D and 3D games with a focus on simplicity and control.

Perfect for indie developers, game jams, and educational projects.

Core Features

🎬 Entity System

Parent/child transform hierarchy with cached matrices.

📷 Camera Control

Smooth lerp-following camera with screen shake.

💡 Lighting & Fog

Real-time lighting shader pipeline.

🎨 Animation

Skeletal animation playback with looping.

🔊 Audio System

Sound effects and streamed music.

🎥 Video Playback

MPEG1 cutscene support for retro style.

💥 Physics Triggers

Sphere collisions and AABB zones.

🌀 Post-Processing

Render-to-texture screen effects.

Quick Start

#include "BCore.h" int main() { bc::Initialize(1280, 720, "My Game"); bc::CameraSystem camera; camera.Initialize(); while (bc::Window::IsOpen()) { camera.Update(); bc::Window::ClearScreen(BLACK); bc::Window::EndDrawing(); } bc::Shutdown(); return 0; }
